title: Data Protection, Confidentiality & Compliance
---

### Types of Sensitive Data:
- Customer information  
- Internal documents  
- Source code  
- HR / employee info  
- Credentials  

### Rules for Handling Data
- Access data only if needed  
- Store files in approved locations  
- Do not use personal cloud accounts  
- Delete files securely  
- Do not email confidential files without encryption  

### Compliance Laws:
- **GDPR**  
- **SOC2 / ISO27001**  

## Interactive Activity – Data Classification  
Categorize items as:
- Public  
- Internal  
- Confidential  
- Highly Confidential
